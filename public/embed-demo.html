Embed demo

Each of these is one iframe and nothing else — the board, and what it takes to solve it. The markup under each one is the markup that draws it. /embed shows a problem from this site's database; /board shows one you bring yourself.

Inside the frame the composer and the source stay out of sight until the solve is decided, as a solving tourney's diagram sheet does.

Today's problem

With no id at all, the frame carries the site's daily problem — the same one the front page is showing — so a page can be pasted once and have something new on it every day.

A problem of your own

/board is the same board with no name on it: no link back here, no branding, and set in the host page's type rather than this site's. It takes the position and the solution in the address instead of a database id, so a page can put up a problem that is not in YACPDB at all — an original, an award entry, whatever it is writing about that week.

The solution goes in exactly as Popeye prints it — no conversion, no JSON, no list of moves. This is what Popeye says about the first of the two problems below, and the whole of it is what goes in the address:

   1.Sa1-c2 ! threat:
          2.Sc2-b4 #
      1...b3*c2
          2.Bg8*f7 #
fen The diagram. The placement alone is enough — 6B1/5p2/8/8/8/1p6/kB6/N1K5 — and the side to move is taken as White unless the FEN says otherwise. A helpmate wants … b on the end.
stip #2, h#3, s#2, or + / = for a study. Write %23 where you mean #, or let the builder below do it.
sol Popeye's solution, copied out as it stands. Line breaks and indentation and all — the indentation is what says which defence belongs to which move.
author The composer. Two or more, separated by ;. Shown under the diagram once the solve is decided, never before.
source, year Where it was published, and when. Shown on the same line as the composer.

Everything after ? has to be percent-encoded, which is no fun to do by hand for a solution with line breaks in it. Paste the pieces into the builder at the bottom of this page and it writes the markup for you.

Other sizes

The board takes the width it is given, or the height left over once the lines around it have taken theirs — whichever is smaller. None of these scrolls.
