Embed demo

Each of these is an iframe of /embed?id=<YACPDB id> and nothing else — the board, and what it takes to solve it. The markup under each one is the markup that draws it.

Inside the frame the composer and the source stay out of sight until the solve is decided, as a solving tourney's diagram sheet does.

The frames on this page are running from the staging copy until the embed is live on the site. The markup under each one carries the address to use, arcade.chessproblem.org.

Today's problem

With no id at all, the frame carries the site's daily problem — the same one the front page is showing — so a page can be pasted once and have something new on it every day.
